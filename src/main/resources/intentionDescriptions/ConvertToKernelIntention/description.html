Asks the AI model chosen in Settings | Other Settings | TornadoInsight | AI-Assisted Transformation for a TornadoVM kernel version of the method, with @Parallel loops. The answer is checked (it must parse, keep the original parameters, and pass the kernel inspections) and problems are sent back to the model, for up to three answers. A diff shows the kernel before it replaces the method; Undo restores the original. Available only when AI-assisted transformation is enabled.
