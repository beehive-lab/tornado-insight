# Data types accepted inside TornadoVM kernels by the DataTypeInspection, read by
# uk.ac.manchester.beehive.tornado.plugins.kernel.SupportedKernelTypes.
#
# Format: one entry per line; blank lines and lines starting with '#' are ignored;
# an entry is a single token without whitespace and belongs to the section header
# ([names] or [prefixes]) above it. Both sections must be present and non-empty;
# anything else is rejected as malformed.
#
#   [names]     a type is supported if PsiType#equalsToText(entry) holds
#   [prefixes]  a type is supported if its canonical text starts with the entry
#               (so "int[]" also accepts int[][], and the AtomicInteger entry
#               also accepts AtomicIntegerArray)
#
# A type added here can also reach the dynamic inspection as a kernel parameter;
# ParameterInitializerTest checks that the harness can generate test data for it.
